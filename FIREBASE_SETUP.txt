WHAT IS FIREBASE?
-----------------
Firebase is Google's free cloud service. We'll use "Realtime Database"
to store your Arduino sensor data in the cloud. The app reads from
the cloud, so judges can see live data from anywhere.

STEP 1: CREATE A FIREBASE ACCOUNT (Free)
----------------------------------------
1. Go to https://firebase.google.com
2. Click "Get started" or "Go to console"
3. Sign in with your Google account (or create one)

STEP 2: CREATE A NEW PROJECT
----------------------------
1. Click "Create a project"
2. Project name: schoolheat-tuklas
3. Disable "Enable Google Analytics" (not needed)
4. Click "Create project"
5. Wait for it to finish, then click "Continue"

STEP 3: CREATE A REALTIME DATABASE
----------------------------------
1. In the left sidebar, click "Build" → "Realtime Database"
2. Click "Create Database"
3. Location: Choose the closest region (asia-southeast1 for Philippines)
4. Click "Next"
5. Start in "Test mode" (allows reads/writes without auth)
6. Click "Enable"

STEP 4: GET YOUR DATABASE URL
-----------------------------
1. You should now see your database
2. At the top, you'll see a URL like:
   https://schoolheat-tuklas-default-rtdb.asia-southeast1.firebasedatabase.app/
3. COPY this URL — you'll need it!

STEP 5: CONFIGURE THE APP
-------------------------
1. Open firebase_bridge.py in Notepad
2. Find this line:
   DEFAULT_FIREBASE_URL = "https://YOUR-PROJECT-default-rtdb.firebaseio.com"
3. Replace it with YOUR actual URL:
   DEFAULT_FIREBASE_URL = "https://schoolheat-tuklas-default-rtdb.asia-southeast1.firebasedatabase.app"
4. Save the file

STEP 6: CONFIGURE THE WEB APP
------------------------------
1. Open the SchoolHeat app in your browser
2. Go to Settings tab
3. In "Firebase Database URL", paste your URL
4. Check "Use Cloud Mode"
5. Click "Connect to Cloud"
6. Status should show: "Connected to Firebase Cloud!"

STEP 7: START PUSHING DATA
--------------------------
1. Connect your Arduino to the laptop
2. Run: python firebase_bridge.py
3. It will read from Arduino and push to Firebase every 5 seconds
4. Open the app on your phone (GitHub Pages URL)
5. You should see live data updating!

STEP 8: SHARE WITH JUDGES
-------------------------
1. Give judges your GitHub Pages URL:
   https://yourusername.github.io/schoolheat/
2. They open it on their phones
3. They see live Arduino data!
4. No ngrok needed, no IP addresses, no same network!

TROUBLESHOOTING
---------------
Problem: "Firebase push failed"
Fix: Check your internet connection. Make sure the URL is correct.

Problem: "Permission denied"
Fix: In Firebase Console, go to Realtime Database → Rules. Make sure it says:
     {
       "rules": {
         ".read": true,
         ".write": true
       }
     }
     Click "Publish".

Problem: "App shows old data"
Fix: The app polls Firebase every 3 seconds. Make sure firebase_bridge.py
     is still running on your laptop.
