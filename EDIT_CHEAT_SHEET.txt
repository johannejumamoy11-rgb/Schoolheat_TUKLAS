  3. ADD / REMOVE / EDIT BUILDINGS
================================================================================

FILE: script.js
SEARCH FOR: const LOCATIONS = [

FORMAT FOR EACH BUILDING:
  { id: 'loc-1', number: 1, name: 'Building Name Here', outdoor: false },

RULES:
  - id must be unique (loc-1, loc-2, loc-3...)
  - number is what shows in the app (1, 2, 3...)
  - name is what users see
  - outdoor: true = outside area (gets +3C in simulation)
  - outdoor: false = inside building

EXAMPLE - ADD NEW BUILDING:
  { id: 'loc-30', number: 30, name: 'New Science Laboratory', outdoor: false },

EXAMPLE - REMOVE BUILDING:
  Delete the entire line including the comma at the end

EXAMPLE - RENAME BUILDING:
  Change the text inside 'name': '...'

IMPORTANT: If you add/remove buildings, you MUST also update the map markers.
SEARCH FOR: MAP_MARKER_POSITIONS
Each building needs x,y coordinates (percentage 0-100) for the map dot.

  4. CHANGE HEAT INDEX DANGER LEVELS
================================================================================

FILE: script.js
SEARCH FOR: function getHeatStatus(heatIndex) {

CURRENT LEVELS:
  < 27  = Safe
  < 32  = Caution
  < 41  = Extreme Caution
  < 51  = Danger
  >= 51 = Extreme Danger

TO CHANGE:
  if (heatIndex < 27) return 'Safe';
  if (heatIndex < 32) return 'Caution';
  if (heatIndex < 41) return 'Extreme Caution';
  if (heatIndex < 51) return 'Danger';
  return 'Extreme Danger';

EXAMPLE - Make it stricter:
  if (heatIndex < 25) return 'Safe';
  if (heatIndex < 30) return 'Caution';
  if (heatIndex < 38) return 'Extreme Caution';
  if (heatIndex < 48) return 'Danger';
  return 'Extreme Danger';

================================================================================
  7. CHANGE BACKGROUND IMAGE
================================================================================

FILE: style.css
SEARCH FOR: school-bg.jpg

TO USE YOUR OWN PHOTO:
1. Put your photo in the assets/ folder
2. Rename it to school-bg.jpg (or edit the CSS)
3. In style.css, change:
   background: url('assets/school-bg.jpg')
   TO:
   background: url('assets/your-photo.jpg')

TO REMOVE BACKGROUND (plain white):
1. In style.css, find:
   background: url('assets/school-bg.jpg') center/cover fixed no-repeat;
2. Replace with:
   background: linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%);

================================================================================
 14. FIX BROKEN TAGS (Common Mistake)
================================================================================

WRONG:  </script>ipt>
RIGHT:  </script>

WRONG:  <div>text</divv>
RIGHT:  <div>text</div>

WRONG:  <button>Click</buton>
RIGHT:  <button>Click</button>

ALWAYS CHECK: Every <tag> has a matching </tag>

================================================================================
 16. EMERGENCY COMPETITION DAY FIXES
================================================================================

APP WON'T OPEN:
  - Undo last change (Ctrl+Z)
  - Save and test again
  - If still broken, use your backup copy

WRONG SCHOOL NAME SHOWS:
  - Search ALL files for "Mahaplag" and replace

CHARTS DON'T SHOW:
  - Record at least 1 reading first (Monitor tab)

COLORS LOOK WRONG:
  - You missed some #d9534f instances
  - Use Ctrl+H Replace All in style.css

BUILD FAILS:
  - Make sure all files are in ONE folder (flat structure)
  - No css/ or js/ subfolders
  - Run: python build.py
