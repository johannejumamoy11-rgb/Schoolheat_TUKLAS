═══════════════════════════════════════════════════════════════════════════════
METHOD 1: ONE-CLICK PUBLIC ACCESS (EASIEST)
═══════════════════════════════════════════════════════════════════════════════

Step 1: Install a tunnel tool (pick ONE)
─────────────────────────────────────────

Option A — Cloudflare Tunnel (RECOMMENDED - Free, most reliable)
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. Download cloudflared:                                                   │
│     https://developers.cloudflare.com/cloudflare-one/connections/          │
│     connect-apps/install-and-setup/installation/                            │
│                                                                             │
│  2. For Windows: Download the .exe and put it in your SchoolHeat folder    │
│                                                                             │
│  3. Open Command Prompt in your SchoolHeat folder:                        │
│     cd C:\Users\Admin\Desktop\SchoolHeat_TUKLAS                        │
│                                                                             │
│  4. Test it works:                                                          │
│     cloudflared --version                                                   │
└─────────────────────────────────────────────────────────────────────────────┘

Option B — ngrok (Free, easy, URL changes each time)
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. Download ngrok: https://ngrok.com/download                              │
│                                                                             │
│  2. Sign up for free at https://dashboard.ngrok.com/signup                  │
│                                                                             │
│  3. Copy your authtoken from the dashboard                                  │
│                                                                             │
│  4. In Command Prompt, run:                                                 │
│     ngrok config add-authtoken YOUR_TOKEN_HERE                              │
│                                                                             │
│  5. Test it works:                                                          │
│     ngrok version                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

Option C — LocalTunnel (Free, no signup, less reliable)
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. Install Node.js: https://nodejs.org                                     │
│                                                                             │
│  2. Test it works:                                                          │
│     npx --version                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

Step 2: Run the one-click launcher
──────────────────────────────────

Open Command Prompt in your SchoolHeat folder and run:

    python start_public.py

OR with Arduino connected:

    python start_public.py COM4

(Replace COM4 with your actual Arduino port)

The script will:
✅ Start the bridge server
✅ Create a public tunnel URL
✅ Print a QR code in the terminal
✅ Save the URL to PUBLIC_URL.txt

═══════════════════════════════════════════════════════════════════════════════
METHOD 2: MANUAL SETUP (If one-click doesn't work)
═══════════════════════════════════════════════════════════════════════════════

Using Cloudflare Tunnel:
────────────────────────

1. Start bridge server:
   python bridge_server.py --host 0.0.0.0

2. In a NEW Command Prompt window, run:
   cloudflared tunnel --url http://localhost:5000

3. You'll see a URL like:
   https://abc123.trycloudflare.com

4. Share that URL — anyone can access it!

Using ngrok:
────────────

1. Start bridge server:
   python bridge_server.py --host 0.0.0.0

2. In a NEW Command Prompt window, run:
   ngrok http 5000

3. You'll see a URL like:
   https://abc123.ngrok-free.app

4. Share that URL!

═══════════════════════════════════════════════════════════════════════════════
METHOD 3: PERMANENT URL (For Multiple Competition Days)
═══════════════════════════════════════════════════════════════════════════════

If you want the SAME URL every time (e.g., for a poster you printed ahead):

Using Cloudflare Tunnel with a fixed subdomain:
─────────────────────────────────────────────

1. Create a free Cloudflare account: https://dash.cloudflare.com/sign-up

2. Add a domain (or use a free subdomain from Freenom: https://freenom.com)

3. Install cloudflared and authenticate:
   cloudflared tunnel login

4. Create a tunnel:
   cloudflared tunnel create schoolheat

5. Route it to your domain:
   cloudflared tunnel route dns schoolheat yourdomain.com

6. Start the tunnel:
   cloudflared tunnel run schoolheat

Now https://yourdomain.com ALWAYS points to your laptop!

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "cloudflared is not recognized"
→ Solution: Add the folder containing cloudflared.exe to your PATH, or move
   cloudflared.exe into your SchoolHeat_TUKLAS folder.

Problem: "ngrok requires authtoken"
→ Solution: Sign up at ngrok.com, copy token, run:
   ngrok config add-authtoken YOUR_TOKEN

Problem: "Connection refused" on phone
→ Solution: Make sure you used --host 0.0.0.0 when starting bridge_server.py

Problem: "Tunnel URL not working"
→ Solution: Check Windows Firewall — allow Python and cloudflared/ngrok.

Problem: "Arduino not detected"
→ Solution: Check Device Manager for the correct COM port. Try COM3, COM4, COM5.

Problem: "URL works but no data shows"
→ Solution: The bridge server might not be reading the Arduino. Check the
   bridge server terminal for error messages.
